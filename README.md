🧠 BrainSpark Quiz

BrainSpark Quiz is an interactive programming quiz web application designed to test and improve programming knowledge in a fun and engaging way.

Users can select a programming language and difficulty level, then answer a series of multiple-choice questions within a 15-second timer for each question. At the end of the quiz, the application calculates the score and provides a performance rating.

 # How to Play
Open the BrainSpark Quiz website.
Click Start.
Select a programming language and difficulty level.
Click Start Quiz.
Choose the correct answer before the 15-second timer expires.
Complete all questions to view your score and performance.
Restart the quiz or continue with a different level.
